# 远程电脑

从一个桌面端通过插件访问另一个桌面端上完整的 DSH 网页。两台电脑都要安装支持远程电脑的插件，不经过手机、不需要域名。

## 建立绑定

在家里常用的 A 电脑打开插件控制台的「远程电脑」，生成并复制绑定信息；到随身的 B 电脑粘贴添加。绑定信息十分钟内有效、只能用一次。

绑定后在 B 点击「在桌面端打开」，即可通过本机地址使用 A 的完整 DSH 网页。默认自动在局域网、直连、IPv6、中转和可用隧道之间选路，网络变化后重选；正常的实时连接不会因为细小的测速差异被打断。

完整网页授权等于能远程操作那台 DSH，所以只向自己信任的电脑发放。

## 窗口

点击后优先由插件随包分发的桌面显示壳打开窗口，而不是交给系统默认浏览器。它不是给最终用户双击安装的独立应用，也不做安装器：按平台作为插件的可选依赖 `dsh-mobile-shell-<os>-<cpu>` 一起装，插件把一次性地址和可选的设备名作为命令行参数交给它。一次点击启动一个进程、开一个窗口，窗口标题带设备名；同一台 B 电脑可以同时开多台 A 电脑的窗口，互不干扰。

平台包的版本独立于插件：壳没改就不抬版本，插件更新也不会重下它。机器上没装对应平台包时自动回退到原来的系统浏览器路径，远程电脑功能照常可用。

Mac 上这个窗口按官方桌面端的样子显示：覆盖式标题栏，红黄绿按钮落在网页左侧栏顶部，拖动与双击最大化照常。壳打开时会在一次性入口上带一个只属于壳的标记，本机代理据此只给这个会话的页面主体启用官方自带的让位与拖动排版；网页根元素保持网页版，桌面服务照常启动。同一个入口用普通浏览器打开时仍是原来的网页版，手机 App 与移动 API 都不参与。Windows、Linux 保持标准系统标题栏。

## 访问时限

每次网页访问允许一小时，临近到期会提示。在 B 的插件控制台主动续期才能继续，到期后须重新打开，绑定关系保留。

停止访问、插件退出或 A 撤销授权会断开网页连接，但不停止 A 上已经运行的任务。

## 加密与凭据

网页字节在两端插件之间加密，线路只转发密文。长期绑定凭据由宿主凭据存储保存，浏览器只持有本次访问的临时会话。默认只监听本机回环，不把浏览器入口开放给局域网。

## 撤销

A 可在「可访问本机的电脑」中撤销 B；B 可移除自己保存的绑定。

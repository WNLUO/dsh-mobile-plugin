# 内置宠物包

这个目录放**随插件发版走**的默认宠物（见 [`docs/pet-overlay.md`](../../../docs/pet-overlay.md) §1）。

- 每个包一个子目录，目录名就是包 id（`[a-z0-9][a-z0-9-]{0,63}`），里面一份 `pack.json`
  加它引用的 `.gif` / `.png`。
- 这里的包**只读**：手机上删不掉，用户想要自己的一份，就用同一个 id 在
  `$DSH_HOME/storages/mobile-plugin/pets/<id>/` 写一份 —— 用户那份会盖住这里的。
- 目录可以不存在、也可以是空的：宿主那边「少几个包」而已，不会报错，用户自己的包照常列。

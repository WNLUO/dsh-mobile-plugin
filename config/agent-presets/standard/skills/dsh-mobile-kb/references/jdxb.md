# 节点小宝线路（国内）

第三方组网 / 内网穿透服务商（iepose，面板里叫「节点小宝」）。它在电脑上装一个设备端，绑定账号后给一条 https 外网域名，手机拨这个域名就能回到这台电脑。跟 ZeroNews 最大的不同：插件只管装设备端、取绑定链接、把用户抄来的域名记成线路；「网页服务」要用户在节点小宝控制台自己建，插件不碰账号。

## 先认清自己站哪边

- 跑在用户电脑上、有本机 shell —— 执行者：自己看面板那页的状态、自己点安装、自己核对外网域名是不是真的能拨。
- 回反馈、够不着用户那台电脑 —— 指导者：一步一步说给他做，请他回报每一步的结果，不谎称自己装过。

## 开查前先问一句（话要短）

「面板里网络 → 中国 → 节点小宝那页，显示的是没装、装了没绑，还是已绑定？」状态那行就能分清卡在哪一步，不用一上来问一大堆。

## 接入是四步，顺序不能换

面板那页写着这四步，回答时按同样的顺序问：

1. **一键安装设备端**：插件下载官方二进制、装成系统服务、自己拉起。会弹一次系统管理员授权（Touch ID 或输密码），让用户确认一下。装好后开机自启，重启 DSH、插件更新都不影响它。
2. **绑定账号**：点「取绑定链接」，在打开的页面里登录并绑定。面板每 3 秒问一次设备端，绑上之后链接自动收掉——看到链接消失就是成功了，不用再手动确认。
3. **建一条「网页服务」**：在节点小宝控制台新建网页服务，内网地址是 `127.0.0.1` 加面板给的端口（默认 18787，以面板上显示的为准），外网域名随便填。
4. **填外网地址并保存**：把分到的 `https://xxx` 域名抄到面板里点「保存线路」。手机在下一轮心跳里看到这条线路，名字显示「节点小宝」。

## 必须选「网页服务」，别选 TCP 服务

这是最容易踩的一条，先说清：**节点小宝的 TCP 服务在这里用不了**。它的 TCP 网关会把 HTTP 形状的流量换掉——实测 GET / POST / HEAD / PUT / OPTIONS 全被回成一张拒绝页——而 App 发出去的就是 HTTP。用户在控制台选了 TCP 服务，域名抄回来也会连不上，不是插件没记上。

面板允许填「域名:端口」（TCP 形状）是为了不把用户填的东西悄悄改掉，不代表那种地址能用。看到有人填了 TCP 服务，直接让他回控制台改成网页服务。

## 几个容易卡住的地方

- **必须装成系统服务，不能改成普通进程跑**：设备身份写在系统目录里、要以 root 跑才存得住。实测普通用户跑，重启后 peerid 变空、线路全掉。所以那一次管理员授权省不掉，这是系统对装服务的规矩。
- **平台**：自动安装只接了 macOS；Windows 这一版没接（面板会说只接了 macOS 与 Linux 的设备端）；Linux 要用户自己装设备端，装好后插件能读到状态。
- **本地管理口**：macOS 是 2080、Linux 是 9118，只在本机回环，插件靠它判断装没装、绑没绑。端口没应答就是没装、没起，或被别的程序占着。
- **端口别记死**：网页服务的内网端口要按面板给的来。插件监听的口改过之后，记得回控制台把网页服务的端口一起改。
- **取不到绑定链接**：已经绑过的设备不再给链接，这是正常现象；超时或连不上，先确认设备端在跑。
- **保存后手机没看到**：地址要下一轮心跳才到手机，让手机切回前台或重连一次；改过地址要重新保存过一次才算。
- **只清空线路不等于停服务**：把地址清空保存就撤掉这条线路；设备端还是系统服务、还会开机自启，要彻底停用得自己去停那个服务，插件不代卸载。

## 已知限制

- TCP 服务这条网关过不去 HTTP，只有网页服务能用；需要 TCP 形状的入口，走 FRP 或自建中转，别在这条上耗。
- 域名由服务商分配，不能自定义；账号与套餐问题归用户，插件不碰。
- iOS 上拨的是 https 域名，没有明文限制的问题；实测仍卡住就先看是不是 TCP 服务、端口对不对。
- 面板只报状态，终判认手机断 Wi-Fi 走流量实测，电脑侧 curl 通只算自查。

## 什么时候停

- 账号、套餐、控制台操作这类事，指导到「该点哪里」为止，不替用户登录、不代建服务。
- 网页服务建了、地址也存了，手机仍连不上：把卡在哪一步（装 / 绑 / 网页服务端口 / 地址保存 / 心跳）说清，标「待定位」，别写「已修复」。
- 用户要的是 TCP 入口或多条线路：如实说这条只适合网页服务，建议换 FRP、IPv6 直连或中转。

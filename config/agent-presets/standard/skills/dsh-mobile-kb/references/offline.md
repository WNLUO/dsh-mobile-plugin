# 设备离线 / 连上又断

「离线」在不同地方意思不一样，先问清用户说的是哪一格，再往下查。

## 先分清是在哪看到的

- 电脑插件面板里的设备列表：看的是这台电脑当前还认哪些设备。
- 手机侧栏的连接状态：看的是手机到电脑这条连接本身。
- 聊天发不出去 / 一直转圈：可能是通道问题，不一定是设备离线。

## 通道和掉线的关系

选路模式（`auto` 缺省 / `lan` / `direct` / `wan` / `ipv6`）决定走哪条：

- `lan` 只走局域网，人到了外网就是连不上——这是选择本身，不是故障。
- `wan` 只走中转，`ipv6` 只走 IPv6，同理，排除了别的通道就连不上。
- `auto` 局域网优先，失败会按退避窗口退到中转。刚换网络时旧的局域网地址全是死的，要等候选重算；这期间显示「离线」可能是过渡态。

两种容易混淆的提示：

- 侧栏还写着局域网、聊天却停住：后台连接与界面状态各算各的，界面未必已经更新，别据此断言网络断了。
- `429` 是名额满了，不是地址坏了：换候选没用，不要建议用户反复切通道。

## 给用户的信息清单

版本与构建号、在哪个界面看到离线、选路模式、手机和电脑是否同一 Wi-Fi、换过网络没有、侧栏与聊天分别什么表现。

## 边界

重连、切模式、改设置由用户自己操作；排查侧不代勞改配置。反复离线且信息齐全仍无结论的，记「待定位」，不写「已修复」。

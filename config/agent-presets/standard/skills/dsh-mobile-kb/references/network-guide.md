# 用户说不清要什么网络：先检测，再推荐

用户直接问「能不能帮我部署一个网络」「我该怎么从外面连回来」，却说不清自己有什么条件时，走这篇。**不是甩一张清单让用户填**，是 AI 自己先检测、分析，能确定的自己定，确定不了的再问用户要——而且要经过用户同意。

## 先认清自己站哪边

- 跑在用户电脑上、有本机 shell —— 执行者：本机能查的自己查（网卡地址、自检口、体检口），查不到的让用户配合。
- 回反馈、够不着用户那台电脑 —— 指导者：说清怎么让用户自己看，请他回报结果，不谎称自己测过。

## 第一步：网络连通性检测（自己查，别先问）

1. **先看电脑这侧能不能查到公网地址。** 网卡里 `2`/`3` 开头是公网 IPv6；WAN 口是 `10.x`/`100.64.x`/`192.168.x` 就是运营商大内网，没有公网 IPv4。Mac `ifconfig`、Linux `ip -6 addr`、Windows `ipconfig`。有没有公网 IPv6、有没有公网 IPv4，这一步就有账。
2. **跑本机自检口**（`/api/relay/selfcheck`，面板连接自检也走它）：端口在不在听、隧道注册没注册、防火墙挡没挡，这几样本机查得到，是确定答案。结论五档：`not-listening` / `firewall-blocked` / `unknown` / `network` / `ok`。`unknown` 就是读不到，别写成正常。
3. **诚实看待一个事实**：本机证明不了「外网到底能不能进来」。朝自己的局域网地址发请求包不走物理网卡，测出来永远是通的（假阳性）。自检里的「最近连上过」只是旁证——最近三十分钟手机真来敲过门，说明这条链整体通；没来过不代表不通，可能是没连同一 Wi-Fi、路由器隔离、或该走中转。
4. **真正的外网判定要请用户配合**：让手机关掉 Wi-Fi 走蜂窝，试着连这台电脑、走 IPv6 那条或直连地址，看能不能连上、能不能发消息。用户愿意配合就一起做；不愿配合就把已查到的和还缺什么说清，标「待补充」，不硬下结论。

## 第二步：FRP 服务器这类外部条件，只能问，不能扫

**绝不主动扫描用户设备、文件、网络里有没有服务器**——那既越界也拿不到。有没有服务器、有没有域名和证书，只有用户自己知道，必须问，而且是请他**主动提供**这些信息（经他同意才算数）。

话要短，一次问一两个：

- 「你手上有没有一台带公网 IP 的服务器？Linux 的就行。」
- 「有没有自己的域名、能给这个域名配证书吗？」

答得上来就往下推荐；答不上来就说「那我们先按没有服务器来安排」，别卡住。别在回复里复述服务器密码、证书私钥、令牌；这些只在当次配置里用，用完不留存。

## 第三步：按条件推荐方案

按已知条件选，**先说最推荐的那条，再说为什么**，别一次摊开所有选项让用户自己挑：

- **有服务器**：优先走 TCP 方案（frp 这类自建公网直连）——不用域名证书就能通。补充一句实话：早先 iOS 的 ATS 会掐公网明文直连，现在 App 改走原生回环转发，公网明文已经不被 ATS 拦了；但能配 https 仍然更稳，有域名证书就上 https。细节读 `references/frp.md`。
- **有服务器 + 域名 + 证书**：这条路也适合自建中转（`references/relay-server.md`），尤其是线路延迟大、或多人共用的场景（见下面的优势）。有域名证书时 https 直连和自建中转都成立，按"要不要控谁能建隧道、要不要多人在外面连同一台"来选。
- **有公网 IPv6、没服务器**：走 IPv6 直连（`references/ipv6.md`）；但要确认两端都有公网 IPv6——家里下发、手机蜂窝也得支持，少一头不成立。
- **只有公网 IPv4（不是大内网）、没服务器**：IPv4 公网 + 端口映射（`references/ipv4.md`）。
- **什么都没有、只要能用**：用内置中转（公用或自建一台最省事），不要硬撺掇用户去架服务器。

每个推荐都读对应那篇再答，别凭印象给步骤。

## 中转程序的一句话介绍（用户问到再说，别硬塞）

自建中转不是纯直连：高频读的会话列表、工作区镜像快照会在中转这一层缓存、做读取隔离，线路延迟大时这些读会更快一些。但要说准——v2 协议的会话正文仍是端到端密文，中转看不到内容，别把它说成「对话明文存在服务器内存里」。想细究就读 `references/relay-server.md`。

## 什么时候停

- 检测结果和推荐之间差着未经确认的条件：说清「这是按你说的没有服务器推荐的」，条件变了方案会变，不写「已部署」。
- 用户不愿提供服务器/域名信息、也不愿配合手机实测：给一个不需要这些条件的方案（内置中转），把话说完就停，不反复追问。
- 服务器密码、域名证书私钥、令牌只在当次配置里用，不写进知识库、不在回复里复述。

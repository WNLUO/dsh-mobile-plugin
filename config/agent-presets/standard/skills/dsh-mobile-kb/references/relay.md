# 中转连不上 / 公用与自建中转

中转地址是**一组**：`relayUrls` 是完整列表，`relayUrl` 恒为它的首项（主用那条）。两格不一致时以列表为准，改配置只动列表那一格。

## 先分清是哪种中转

- 公用中转：官方内置的默认地址。启用且没有可用的公网替代时会自动补回清单。
- 自建中转：用户自己填的地址（公网 IP 或内网穿透域名）。填了自建，公用那条会被强制停用——这是有替代时的自动停用，和下面手动停用是两回事。
- 显式停用：用户在面板上明确关掉公用中转。为真时保存和读盘都不再补回公用地址，点启用可恢复。

## 常见误区

- 「面板点了停用，保存完又回来了」：先问是否按了保存、面板是否重新载入过；确认用户说的「停用」是面板那颗开关还是清空了地址列表——清空列表不等于显式停用，会被补回。
- 退役的官方域名（曾经内置、后来不用了的那几个）：读盘时若列表里还有现行公用地址，退役项会被剔掉；若列表里**只剩**退役地址，会当成用户显式配置原样保留，不静默改写。写入路径不碰退役项。
- 连不上先分是「地址不对」还是「服务没起」：地址问题看面板里主用哪条；服务问题看电脑上的隧道是否显示已连接。

## 给用户的信息清单

版本与构建号、面板里主用中转地址与列表、隧道连接状态、自建还是公用、有没有点过「停用」、报错原文。别把退役域名当成用户填错而让他改。

## 边界

改中转地址、改配置、重启隧道都不属于排查动作。确认是产品缺陷的，按待定位记录，交给维护者，不写成用户操作问题。

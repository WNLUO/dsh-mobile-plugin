# ZeroNews 线路（国内）

账号制的内网穿透服务，给一个 `https://xxx` 域名拨回这台电脑。插件把客户端、隧道、域名一条龙接管：面板点「开始接入」→ 装客户端 → 浏览器登录 → 粘一次 AuthToken → 之后只剩「连接 / 断开」。它顶替的是中转或自建入口，鉴权和配对仍在电脑这侧，ZeroNews 只看到域名那一层。国内网络用不着翻墙，这是它相对 Cloudflare 快隧道的主要好处。

## 先认清自己站哪边

- 跑在用户电脑上、有本机 shell —— 执行者：自己看面板那页的 phase、自己点连接、自己 curl 域名验体检口。
- 回反馈、够不着用户那台电脑 —— 指导者：说清点哪里、粘哪串，请他回报面板上显示的结果，不谎称自己连过。

## 开查前先问一句（话要短）

「面板里网络 → 中国 → ZeroNews 那页，显示的是已连接、未连接，还是连接失败？」能直接答就往下走；说不清让他念状态那一行。

## 第一次接入是面板带着走，不是去控制台建隧道

这点先纠正，别照旧印象指导：**用户不用去 ZeroNews 控制台新建隧道、也不用把域名抄到直连地址栏**。面板那页四步走完就行：

1. 点「开始接入」：插件按平台从官方下载客户端（macOS 的 arm64 / x64、Windows x64、Linux x64 / arm64），第一次要等几十秒。
2. 自动打开登录页（`user.zeronews.cc/setup`）；没打开就面板会给出地址，手动访问登录。
3. 登录后进「快速开始」，点 AuthToken 右边的「复制」。
4. 回到面板粘上，点「保存并连接」。插件开始起客户端、建一条指向本机端口的 HTTPS 隧道、读出域名。

token 只进一次本机客户端配置，面板不留存、不显示；之后这台机器算「有身份」，面板收起粘贴框，只剩连接 / 断开，**不用每次重来**。

## 连上之后发生了什么

- 已有一条 HTTPS 隧道就复用，没有才用 `add https` 建一条——免费档只有一条隧道额度，重复建会被拒。
- 拿到域名就写进独立的状态格，随心跳和总控报给手机，线路名显示「ZeroNews」。断开时这格清空，手机那边跟着撤掉这条线路。
- 插件重载、自动更新、客户端偶发退出后，会从 3 秒起退避自动重连（最长 60 秒一次），**别让用户对着面板反复点「连接」**。
- 只认 active 的 HTTPS 隧道：TCP 隧道是「主机:端口」，不是能拨的 http 地址，插件不会收。

## 常见症状

- **一直停在安装/连接中**：多半是下载官方客户端慢或网络不通。第一次慢属正常，超过一分钟没动静再查网络，别催用户重装。
- **连接失败，提示 AuthToken 写入失败**：token 没复制完整（少字符、带了空格）。回「快速开始」页重新复制整串；还不行就换「浏览器登录」那条老路。
- **提示等待浏览器确认超时**：浏览器那条路等了 5 分钟没等到登录，让用户改走 AuthToken 那条。
- **提示客户端已连上但没拿到隧道地址**：先等一会儿再点连接；仍没有就去 ZeroNews 控制台看是不是免费额度已经占满了（只有一条），把旧隧道删掉再试。
- **提示客户端意外退出**：插件会自己安排重连，等它退避重试即可；连续失败再查网络。
- **面板显示已连接、手机里没有这条线路**：地址要等下一轮心跳才到手机（通常几十秒），让手机切回 App 前台或重连一次；另外确认电脑这侧没关掉地址上报。
- **面板显示未连接、地址也空了**：那是断开后的正常状态，不是掉线；要恢复就点「连接」，不需要再粘 token。

## 本机测试要从头来

反复测接入流程时别靠「断开」——断开只停隧道、撤域名，本机客户端的登录身份、配置和插件的「已绑定」标记都还在，再点连接会直接复用旧身份，不是干净起点。ZeroNews 那页概览卡有「彻底清理」：确认后停进程、跑官方 `zeronews reset` 清本机 Token / config.yml / 运行时与日志、删掉插件下载的客户端缓存，并把插件状态一起清掉；下次「开始接入」从下载客户端那一步重新走。

它只清本机：控制台里的客户端记录和云端隧道还在，免费档名额不会因此释放。macOS 上 reset 要管理员权限，插件会弹系统授权框（点一下确认即可，不用开终端敲 sudo）；用户取消授权就如实说取消了，重新点「彻底清理」再确认一次。其它失败时缓存二进制也会留着，重新点按钮再试即可，别让用户去终端手动敲命令。

## 已知限制

- 免费档一条隧道、域名由服务商分配，不能自定义；要自定义域名、多条隧道得看它自己的套餐，这不是插件能绕的。
- 隧道断了地址就换一个，别让用户把这个域名当固定入口贴到别处记着。
- 换电脑或重装客户端要重新登录、重粘 token；token 那条路走不通时才退回浏览器登录。
- macOS 上如果 `/Applications/zeronews` 里已经有一份（用户自己装的），插件会优先复用它，别再装第二份。
- 面板只报状态，终判认手机断 Wi-Fi 走流量实测：`curl https://域名/api/mobile/v1/health` 有回复只算电脑侧自查。

## 什么时候停

- 注册、实名、套餐额度这类账号问题，原样交回用户，别替他操作账号。
- 客户端装不上、域名一直拿不到、实测仍不通：把卡在哪一步（下载 / token / 隧道地址 / 心跳）说清，标「待定位」，别写「已修复」。
- 用户要长期稳定、要自定义域名、要多条线路：如实说这条免费档不够，建议换中转或自建入口，不硬撑。

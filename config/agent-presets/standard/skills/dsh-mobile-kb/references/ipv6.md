# IPv6 直连拨不通（公网 IPv6 进不来）

手机在外网要用「IPv6 直连」回家，要求两端同时成立：电脑拿到的是**公网 IPv6**，家里光猫/路由器的 IPv6 没关、又不把入站拦掉。少一头就不通。这一篇负责把它查到底。

## 先认清自己站哪边

- 跑在用户电脑上、有本机 shell —— 执行者：自己查地址、自己 curl 光猫后台、自己回读确认。
- 回反馈、够不着用户局域网 —— 指导者：把下面每一步说给用户做，请他回报结果；不谎称自己登过后台。

## 开查前先问一句（话要短）

「路由器/光猫的 IPv6 开了吗？IPv6 防火墙关了吗？」用户能直接答就往下走；答不上来再说「把后台密码发我，我登进去看」。别上来一大段。

## 按顺序查，别跳

1. **电脑有没有公网 IPv6。** 在本机看网卡的 IPv6：`2` 或 `3` 开头（如 `240e:`、`2400:`、`2600:`、`2a00:`）是公网；`fe80:` 是链路本地、`fd00:/fc00:` 是内网段、`::1` 是回环、`2001:db8::` 是文档示例，这几种都不算。Mac 用 `ifconfig`、Linux 用 `ip -6 addr`、Windows 用 `ipconfig`。**没有公网 IPv6 要先分两种原因**：一是设备没开 IPv6 或没拿到前缀委派（PD），能修，转第 2 步；二是运营商本身就不下发公网 IPv6（不少海外宽带、移动网络，以及国内部分 CGNAT 线路），这种改设备没用，直接看「什么时候停」。别把第二种当成第一种反复折腾设备。
2. **进光猫/路由器，看 IPv6 开关和防火墙。** 后台地址按地区试：国内常见 `192.168.1.1`、`192.168.0.1`、`tplogin.cn`（TP-Link）、`miwifi.com`（小米）、`falogin.cn`（迅捷）、`router.asus.com`（华硕）；海外常见 `192.168.0.1`、`192.168.1.1`、`10.0.0.1`、`tplinkwifi.net`、`router.asus.com`、`myrouter.local`，运营商送的网关多是 `192.168.1.1` 或机身贴纸上的地址。这些只是起点，不是账号密码。要找的是两样：IPv6 本身有没有启用、IPv6 防火墙/入站过滤有没有拦（有的叫 IPv6 Firewall、有的叫 WAN 入站过滤）。防火墙这项是要**关**的。
3. **进不去后台、找不到型号怎么办。** 先问设备品牌型号和运营商，让他按型号查超级管理入口；查不到就请他提供型号继续找，不要编一个账号密码骗他。**但有一种情况要早认出来**：运营商送的网关（海外尤其常见，如 Comcast、BT、DT 那些租借网关）常把管理员权限锁了，用户手上只有普通账号、根本改不了 IPv6 防火墙。撞上这种就明说这台改不动，别让他一遍遍找超级密码；转「什么时候停」走中转或隧道。已知的一台设备可参考 `docs/ipv6-gateway-inbound.md`（华为 HN8156XR-10：电信定制后台 `192.168.1.1` 没有 IPv6 防火墙开关，要去华为原厂高级界面 `192.168.1.1:8080`，登录后到安全→防火墙→IPv6 防火墙关掉）。那只是国内一台个例，别当成通用账号密码或通用入口。
4. **改完回读确认。** 执行者在后台把开关改完后，重新拉一次页面看当前值是不是目标值（上面那台设备就是回读 `IPv6Firewall` 变成 `0`）。指导者请用户截个图或念一下当前值。没回读不算改成功。
5. **端到端终判：手机断 Wi-Fi 走流量。** 电脑侧的自检只能证明「有公网 IPv6、设备放行」，不能证明外网真能进来。真正的判定是手机关掉 Wi-Fi、用蜂窝，App 里连这台设备、走 IPv6 那条路，看能不能连上、聊天能不能通。连上了才算办成。**但这条测试有个前提**：手机这侧的蜂窝网也得有 IPv6——多数运营商支持，也有只给 IPv4、或走 NAT64 没有公网 IPv6 的，这点因地区、运营商、套餐而异，别凭印象断。手机没有 IPv6 时，这条路本身就不成立，别误判成家里设备的问题；确认手机这侧没 IPv6，转「什么时候停」。家里这边连不上回到第 1、2 步接着查，别停在这里。

## 几个坑

- 国内家宽的 IPv6 前缀会变、光猫重启或运营商远程下发配置之后，IPv6 防火墙可能自己变回「开」，得重来一次；海外运营商那边同样可能改配置。
- 关 IPv6 防火墙通常是全局的，局域网里所有设备的 IPv6 都放到公网可入站了，不该对外露的服务别开着。
- 运营商送的锁死网关（国内海外都有）改不了 IPv6 防火墙，不是没找到入口，是没权限；别在这上面耗。
- 公网 IPv6 两端都要有：家里下发、手机蜂窝也得支持。少一头这条路就不成立。
- 电脑侧的面板状态只报「设备数 / 最后在线」，看不到手机当前走哪条通道；别拿它当 IPv6 通的证据，终判只认手机断网实测。
- 后台密码只在当次登录里用，用完不留存、不写进任何记录、不在回复里复述。

## 什么时候停

- 运营商根本不下发公网 IPv6、或网关锁死改不动、或手机蜂窝没有 IPv6：如实说这台环境目前走不了 IPv6 直连，告诉用户可改用中转或两条隧道（直连隧道、点对点隧道），不写「已修复」。
- 电脑压根没有公网 IPv6、而设备后台又改不出来：同上，不在这条路上死磕。
- 试过常见入口、问过型号还进不去后台：把卡在哪一步说清，请用户接着提供型号或后台截图，不要假装查完。

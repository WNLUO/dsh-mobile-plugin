# IPv4 公网直连（判断有没有公网、端口映射）

有些用户家里有公网 IPv4，可以把电脑直接搬到公网，不必用中转或内网穿透。这条路比 IPv6 多一道端口映射，但判断和验收跟其他自建方案共用一套（见 `references/selfhost-common.md`）。

## 先认清自己站哪边

- 跑在用户电脑上、有本机 shell —— 执行者：自己查公网 IP、自己判断 CGNAT、自己进路由器做映射。
- 回反馈、够不着用户局域网 —— 指导者：一步一步说给用户做，请他回报结果，不谎称自己登过后台。

## 开查前先问一句（话要短）

「路由器后台进得去吗？知道宽带是公网 IP 还是大内网吗？」能直接答就往下走；答不上来再说「把路由器后台密码发我，我登进去看」。别上来一大段。

## 按顺序查，别跳

1. **判断是不是公网 IPv4。** 在电脑上查出口 IPv4（浏览器搜"我的 IP"或 `curl` 一个回显服务），再在本机网卡上看 WAN 口地址，两个比对：
   - 一样 → 大概率是公网 IPv4，继续。
   - 不一样、或 WAN 口是 `10.x`、`100.64.x`（运营商大内网 CGNAT）、`172.16-31.x`、`192.168.x` → 没有公网 IPv4，端口映射没用，转「什么时候停」走 IPv6、frp 或中转。别在路由器上瞎映射。
2. **有公网才做端口映射。** 进路由器后台，把某个公网端口转到电脑上插件服务监听的端口（默认 `51887`，改过就以状态里报的实绑端口为准）。选一个没被占的高端口；一台路由器映射一条，多台电脑各配各的。映射完在手机流量下（断 Wi-Fi）测那个端口通不通。
3. **填哪个栏。** 没域名：直连地址填 `http://公网IP:映射端口`。有域名：先按 `references/selfhost-common.md` 用 DDNS 把域名绑到公网 IP，再填 `https://域名`（有反代终止 TLS）或 `http(s)://域名:端口`。别填进 IPv6 栏或 TCP 直连栏——那是别的通道。
4. **改完回读确认。** 执行者回读路由器的映射表，看端口和内网地址是不是目标值；指导者请用户截图或念一下。然后在手机流量下实测连接，不通回到第 1、2 步接着查。

## 上手机前验收

按 `references/selfhost-common.md` 那四条过一遍：体检口、鉴权、流式、大文件。公网直连把服务暴露在外，鉴权那条尤其别省。

## 几个坑

- 公网 IP 会变（宽带重拨、运营商调整）：没域名就得跟着改地址；有域名配 DDNS 自动追。
- 端口映射是全局的：映射进来的端口对公网所有人可见，别映射到不用的服务；鉴权没生效先别用。
- 运营商可能封常用端口（80/443 之类）：挑高端口，或用反代把公网 443 转到内部端口。
- 电脑侧面板只报「设备数 / 最后在线」，看不到手机当前走哪条通道；终判认手机断网实测。

## 什么时候停

- 不是公网 IPv4（CGNAT/大内网）：如实说做不了 IPv4 公网直连，指去 IPv6、frp 或中转，并说明是运营商分配决定的，不是设备没配好。
- 后台进不去、映射做不了：问品牌型号、按型号找入口，查不到请用户提供型号或截图，不硬编账号密码、不假装查完。
- 映射做完实测不通、又查不出原因：标「待定位」，说清卡在哪，不写「已修复」。

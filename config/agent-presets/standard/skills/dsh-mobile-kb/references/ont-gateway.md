# 进不去光猫后台、忘了后台密码（自有设备的排查）

IPv6 直连要进光猫关防火墙、端口映射要进光猫做映射，都卡在同一件事：用户手上没有能登录后台的管理员密码。运营商定制光猫的密码常被 TR-069 定期轮换，贴纸上的普通账号进不去。这一篇讲怎么在**用户自己的设备**上把这个问题查下去。

主线是**按设备型号、运营商、固件主动上网查当下做法**：光猫型号和固件太多，运营商定制固件还会变，任何现成工具都只覆盖一部分老设备。那个光猫凭据自查工具（`WNLUO/ung220z-tool`）可以试一招，成功最好，不成也不代表没救 —— 换关键词继续查，别拿它失败当结论。拿到密码、改完开关之后怎么验收，回到 `references/ipv6.md` 或 `references/ipv4.md`。

## 先认清自己站哪边

- 跑在用户电脑上、有本机 shell、能联网查资料 —— 执行者：自己查型号和指纹、自己上网找做法、自己跑工具试、自己回读确认。
- 回反馈、够不着用户局域网 —— 指导者：问清型号、运营商和贴纸信息，自己先联网查到做法再说给用户做；请他回报结果，不谎称自己登过后台、跑过工具。

## 开查前先问一句（话要短）

「这台光猫是你自己的吗？什么型号、哪家运营商？」自有设备才往下走；贴纸信息接着问。别上来一大段。

## 先确认能碰

只针对用户**自有设备**：找回自己忘记的密码、迁移自己的宽带配置。用户说不清设备归属、或是别人的光猫、公司/房东的网关 —— 停，不提供提取方法，转「什么时候停」。这是前提，不是走过场的免责声明。

## 按顺序查，别跳

1. **先看贴纸。** 光猫背面 S/N 标签常有「用户名 user / 密码 xxxxxxxx」，先用它试普通后台。运营商定制机常把 Web 普通账号和超级管理员分开，贴纸那组只能进普通页；能进普通页也有用 —— 从页面读固件信息、型号版本。
2. **攒齐上网查的素材**：设备完整型号、运营商、固件版本、Web 后台地址和页面标题。能登录普通页就从页面里读；登不上就问用户拍贴纸和后台页。有工具在电脑上时，跑一下家族识别拿指纹：`python3 -m ontkit probe -H <光猫IP>`，它会打印 `Server` 头和页面标题；也可看有没有 `telnet.gch` 接口，返回 404 就不是九联/吉比特那套 `.gch` 固件。
3. **主动上网查，这是主线。** 按「型号 + 运营商 + 超级管理 / Telnet / 固件版本」这类词搜，找当前有效的进后台做法：厂商文档、近期的实操贴、运营商定制机的专门教程都看。搜到做法先对一遍型号和固件版本，再用上面攒的指纹核对是不是同一台 / 同一类；老旧教程对新固件多半失效，别照搬。查到的命令先判断风险，不因为「网上这么写」就直接执行，更不要照抄到回复里让用户盲试。换着关键词多查几轮，一次搜不到不算查过。
4. **工具只作一次尝试。** 仓库那套对部分老机型有用：UNG220Z 是作者真机验证，其余是公开案例或未验证。按家族试对应入口 —— 九联 / 吉比特 `.gch` 走主脚本，中兴系走 `webFac` 工厂模式，烽火走 `telnetenable.cgi`，华为 ssmp 只做登录并尝试开 Telnet。记下工具打印的指纹行和退出码；不成只说明这一招不适用，回到第 3 步换词继续查，别停在这里。
5. **拿到密码后回到原问题。** 进后台关 IPv6 防火墙 / 做端口映射，改完回读确认（见 `references/ipv6.md` 第 4 步）。后台密码只在这次用，用完不留存、不写进任何记录、不在回复里复述。

## 几个坑

- 工具不是通用解：新固件接口路径会变，运营商也可能关掉工厂模式；它失败只说明这一招对这台不管用，不是这台设备没救。它覆盖的也只是老设备常见家族，别把某个型号的案例当成通用做法。
- 上网查别只搜一次：换完整型号、运营商名、固件指纹、「超级管理 / 开 Telnet / 默认超密」几组词轮着来；注意资料发布时间，老教程对新固件常常已经失效。查到的命令先核对型号和风险，别照单全收。
- Web 登录和 Telnet 是**两套账号库**：Web 密码进不去 Telnet 是常事，工具会依次尝试贴纸账号、超级管理账号、从 Web 页读到的 Telnet 项；用户若知道两者口令不同就提前说。
- 口令里含 `%` 一类字符时，拼进 URL 会被当成转义、服务器返回 400；工具已处理，手工拼 URL 时别忘了编码。
- 连续登录失败（通常 3 次）会让设备进入延时校验：**立即停止重试**，静默等 10～30 分钟再说。别一遍遍试把设备锁死。
- 国内家宽（移动定制的九联、吉比特、中兴为主）和海外差异大：海外运营商租借网关（Comcast、BT、DT 等）常把管理员权限锁死，用户手里只有普通账号，找回密码也改不了防火墙 —— 直接转「什么时候停」。国内也有类似的锁死网关，别把某一台设备的入口当成通用账号密码或通用入口。
- 光猫重启、TR-069 远程下发之后密码可能又轮换，之前拿到的会失效。

## 什么时候停

- 不是用户自有设备、或归属说不清：停，不提供提取方法。
- 运营商锁死网关、没有管理员权限：如实说这台改不动，转中转或两条内置隧道（直连隧道、点对点隧道）；不写「已修复」。
- 多次失败进了延时校验：停，等 10～30 分钟再试；还不行就请用户提供指纹行和退出码，标「待定位」。
- 按型号和运营商上网查过多轮、工具也试过仍拿不到：把卡在哪一步、查到什么、指纹和退出码说清，标「待定位」继续找；只说一句「工具不支持」就交回，不算查过。

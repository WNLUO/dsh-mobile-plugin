# 回环端口被别的程序占用（局域网能连、隧道 403 或外面进不来）

本机另一个程序抢了 `127.0.0.1:18787` 时，局域网直连照常通，但公网隧道转回来的流量打到那个程序，常见表现是隧道地址返 `403`、手机从外面进不来。**先看插件是否已自动绕开，别一上来就让用户结束进程或换端口。**

## 先认清自己站哪边

- 跑在用户电脑上、能在本机动手（curl 到本机端口、看本机状态）—— 执行者：自己查绑定、自己看状态、自己验回环体检，查不到的再让用户配合。
- 回反馈、够不着用户局域网 —— 指导者：一步一步说给用户做，请他回报面板状态和实测结果，不谎称自己动过手。

## 开查前先问一句（话要短）

「插件版本多少？网络页那条直连地址是绿的还是红的？手机在同一个 Wi-Fi 还是外面？」能直接答就往下走；说不清再让他念状态行或截图，别上来一大段。

## 新口径：插件自己绕，不必先动用户配置

插件升级后会分配一条**专属回环入口**：只监听 `127.0.0.1`，端口独立落盘，和 18787 无关。此后新建的公网线路（Cloudflare、frp、ZeroNews）由插件生成，指向这条入口，不再依赖 18787；发现回环被占、或回环体检返回的不是本插件，就自动绕开，地址经总控下发，手机不用重配。绕不开时面板会弹窗，说明端口被占、自动绕开做了什么、还剩哪几步只能用户处理。所以：

- 先对版本：旧插件没有这条能力，才走下面的兜底步骤；新插件不要替用户做那几步。
- 面板已绕开、线路显示可用时，直接进终判，不要让用户结束进程、换端口或删旧隧道。
- 弹窗给了原因码就按弹窗指引领，不跳过弹窗自己猜。

## 按顺序查，别跳

1. **先看状态，不猜。** 执行者自己看状态里的实际入口、是否被绕开、兜底原因码；指导者请用户念这几行或截图。回环体检只认本插件的 health JSON，不是 200 就算通；面板标红就是证据。
2. **分清「局域网能绑」和「公网落点能用」。** 端口检查的「可用」只回答局域网能不能绑（`0.0.0.0` 绑得上），不代表隧道落点可用——别人占的是 `127.0.0.1` 时，局域网照通、隧道 403 正是一对典型现象。别拿局域网 200 当外网通。
3. **看各条线路指向哪。** Cloudflare / ZeroNews / frp 分别按 `references/cloudflare.md`、`references/zeronews.md`、`references/frp.md` 对状态行和地址。新插件生成的线路应指专属入口；仍指 18787 的，多半是老配置或外部软件里手填的目标。
4. **自动兜底怎么起。** 绕不开、又暂时没有可用公网线路时，插件会临时启自带 Cloudflare 快隧道，落点走专属入口；它依赖本机 `cloudflared` 可用，起不来时弹窗会如实说。国内不少网络连不上 Cloudflare 边缘（出站 7844），海外一般可达但不保证；按 `references/cloudflare.md` 转 ZeroNews / 节点小宝或中转。
5. **外部穿透软件里手填的目标，插件改不到。** 这类只能按弹窗指引让用户自己去改目标或换端口；先把这条边界说清再交回。
6. **端到端终判：手机断 Wi-Fi 走流量。** 电脑侧自检只作自查。让手机关掉 Wi-Fi 用蜂窝，连这台设备、试聊天流式和大文件（按 `references/selfhost-common.md` 四条过一遍），能通才算办成。国内海外运营商的蜂窝环境不一样，别拿一台设备的结果当通用结论；本机测出的 200 / 403 都不算终判。

## 已知边界

- 老 ZeroNews 隧道落在旧端口时**不会被自动删除**：官方未公开删除参数，免费档只有一条，删错不可回滚。它的公网域名不变，但被遮蔽期间这条线路不可用，手机走自带 Cloudflare 兜底；别把「域名还在」当成这条线路还能用。
- 外部穿透软件里手填的隧道目标插件改不到，只能弹窗指引。
- 自带 Cloudflare 兜底依赖本机 `cloudflared` 可用，没有它这条路起不来，弹窗会如实说。
- 端口检查的「可用」只回答局域网能不能绑，不代表公网落点可用；以状态里的实际入口和兜底结果为准。

## 什么时候停

- 版本旧、确实绕不开，才把兜底步骤交回用户：结束占用 18787 回环的进程，或换端口后重建指向新端口的隧道（ZeroNews 旧隧道要用户自己在控制台删）。**这是老版本或绕不开时的最后一步，不是首选建议**；执行者不替用户结束进程、不删云端隧道。
- 弹窗给了原因码，按指引仍不通又查不出原因：把卡在哪一步（回环体检 / 线路落点 / 兜底 / 手机实测）说清，标「待定位」，别写「已修复」。
- 用户不愿配合手机流量实测：把已查到的和还缺什么说清就停，不硬下结论。
